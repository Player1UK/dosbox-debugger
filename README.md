Windows can be re-arranged, and snap to grid of titlebar height and character width.

Code is disassembled recursively, so that data entries embedded within the code don't appear.
Labels and proc labels are identified.

New disassembled code entries are added when their address is referenced, either manually or via indirect jumps.

The whole code section is shown, split into segments.

Separate Data and Stack views.
Changes to Data and Stack are shown.
